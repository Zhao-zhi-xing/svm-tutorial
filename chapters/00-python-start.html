2  第一次独立训练 SVM：纯 Python 入门

本章适合第一次上手。配套Notebook只使用Python、scikit-learn、NumPy、pandas与Plotly，不导入本项目的 lab 辅助模块，不读取其他章节状态，不需要R，也不下载外部数据。Iris从scikit-learn内置数据加载。

2.1 下载并运行

下载完整入门Notebook。在VS Code打开它，选择项目 .venv 的Python内核，点击“全部运行”。也可以复制到任意目录，在自己安装好依赖的Python环境中运行。

python -m pip install -r requirements.txt
python -m pip install -r requirements-notebook.txt

Notebook目录同时交付依赖清单，单独下载Notebook后可按该清单安装。VS Code需要Python和Jupyter扩展；Quarto扩展用于编辑教程源码。生成HTML教程本身的双语言构建仍采用knitr+reticulate，纯Python Notebook的运行不依赖它。

2.2 实验完整展开的流程

  1. 载入150个Iris样本及4个数值特征，保留原始行ID。
  2. 分层划分105个训练样本、45个测试样本，验证ID互不重叠。
  3. 使用 Pipeline(StandardScaler, SVC)，每个训练折独立标准化。
  4. 训练集内五折交叉验证选择C与γ，共9种配置。
  5. 参数确定后才计算测试accuracy、macro-F1、混淆矩阵与错误样本。
  6. 用Plotly显示混淆矩阵、CV参数热图；保留每个参数的均值与标准差。

Notebook中的导入、数据、模型、搜索、评估和绘图均完整展开。它在干净Python内核中从头执行并保留结果，方便核对。

2.3 先读懂三个输出

最佳CV分数来自训练集内部，测试分数来自未参与选参的45个样本。两者对应不同问题；不要在查看测试表现后继续改参数，再把同一测试集称为最终评估。

混淆矩阵的行是真实类别，列是预测类别。训练模型使用全部4个特征；本例没有用二维散点冒充四维决策边界。支持向量数量是模型结构信息，不能替代测试指标。

2.4 修改练习

先预测增大C可能造成什么变化，再改变一个预先规定的网格，完整重新执行。记录选参结果，说明实验协议的改变。若反复尝试导致测试集参与决策，应另设最终评估数据。继续阅读软间隔、核方法和重复评估章节，将程序与原理对应起来。
