11  Python / R 完整入门实验

本章要回答：怎样把已经理解的模型与评估原则落实成一段可独立复现的程序？

前置知识：前面理论与基本 Python 或 R 语法。完整展示数据、折内标准化、选参、重拟合和测试。

11.1 准备与实验目标

在教程项目根目录运行代码。Python 安装 requirements-notebook.txt 中的依赖；R 需要 e1071。网页用 Python/R 标签切换两套完整步骤，图形无需保持运行中的语言会话。

用 Iris 的4个测量特征预测3类花。数据已保存相同训练/测试与五折编号，两种语言不重新随机划分。训练105个、测试45个；选择指标为 macro-F1，候选为3种C×3种γ。

下载可独立运行的 Python Notebook。Notebook 内嵌同一份 Iris 数据与划分，下载后不依赖本项目辅助函数。

learn_scale <- function(X) {
  mu <- colMeans(X)
  sd <- sqrt(colMeans(sweep(X, 2, mu, "-")^2))
  sd[sd == 0] <- 1
  list(mu=mu, sd=sd)
}
apply_scale <- function(X, state) sweep(sweep(X, 2, state$mu, "-"), 2, state$sd, "/")
f1_macro <- function(truth, pred, labels) mean(vapply(labels, function(k) {
  tp <- sum(truth == k & pred == k)
  denominator <- sum(truth == k) + sum(pred == k)
  if (denominator == 0) 0 else 2 * tp / denominator
}, numeric(1)))

11.3 在训练集内部选择参数

Python Pipeline 把标准化放进每次拟合；GridSearchCV 每折只在该折训练部分学习均值与标准差。R 显式写出两个循环：外层遍历参数，内层遍历验证折；每一折重新学习标准化。

R 的 scale=FALSE 防止 e1071 再做一次自动缩放。这里用总体标准差与 Python 一致。两种语言的核参数相同，平分时都选参数排序中的第一项。

11.6 将程序与理论逐项对应

  • SVC(kernel="rbf") 对应核软间隔；C 是违例惩罚，gamma 定义标准化坐标中的相似度。
  • 多分类 SVC 内部使用 OvO；decision_function_shape="ovr" 只改变输出分数形状，不能把训练改成 OvR。
  • LinearSVC 常用 squared hinge，与本教程推导的普通 hinge 不同；对比时需注明损失、截距处理和多分类目标。
  • 需要显式 OvR 训练时，可用 OneVsRestClassifier 包装二分类器。不要根据分数数组列数猜测训练策略。

11.7 检查教学 SMO，而不只比较标签

下面显示前面成对更新逻辑的完整教学实现。读每个分支时对应可行区间、曲率与截距公式；它跳过零曲率对，适用范围已在 SMO 章说明。

class LinearSMO:
    """教学版线性 C-SVM：成对更新，完整扫描；不含缓存或 shrinking。"""
    def __init__(self, C=1.0, tol=1e-4, max_iter=3000, record_history=False):
        self.C, self.tol, self.max_iter = float(C), float(tol), int(max_iter)
        self.record_history = record_history

    def fit(self, X, y):
        X, y = np.asarray(X, float), np.asarray(y, float)
        if X.ndim != 2 or len(y) != len(X) or set(np.unique(y)) != {-1., 1.}:
            raise ValueError('X 必须为二维，y 必须包含 -1 和 +1 两类')
        if self.C <= 0 or not np.isfinite(X).all():
            raise ValueError('C 必须为正，X 必须有限')
        n = len(y)
        K = X @ X.T
        a, b = np.zeros(n), 0.0
        self.history_ = []
        def snapshot(pair=None, bounds=None):
            if not self.record_history:return
            w=(a*y)@X; margins=y*(X@w+b); slack=np.maximum(0,1-margins)
            residual=np.where(a<1e-8,np.maximum(0,1-margins),np.where(a>self.C-1e-8,np.maximum(0,margins-1),abs(margins-1)))
            primal=float(.5*w@w+self.C*slack.sum());dual=float(a.sum()-.5*w@w)
            self.history_.append({'alpha':a.tolist(),'w':w.tolist(),'b':float(b),'margins':margins.tolist(),'slack':slack.tolist(),'residuals':residual.tolist(),'primal':primal,'dual':dual,'gap':primal-dual,'kkt':float(residual.max()),'equality':float(abs(a@y)),'pair':pair,'bounds':bounds})
        snapshot()
        for iteration in range(self.max_iter):
            changed = 0
            for i in range(n):
                E = K @ (a*y) + b - y
                r = E[i]*y[i]
                if not ((r < -self.tol and a[i] < self.C-1e-9) or (r > self.tol and a[i] > 1e-9)):
                    continue
                # 最大误差差值优先；若该对受盒约束阻塞，尝试其他 j。
                for j in np.argsort(-abs(E[i]-E)):
                    if i == j:
                        continue
                    ai, aj = a[i], a[j]
                    if y[i] != y[j]:
                        L, H = max(0, aj-ai), min(self.C, self.C+aj-ai)
                    else:
                        L, H = max(0, ai+aj-self.C), min(self.C, ai+aj)
                    eta = K[i,i]+K[j,j]-2*K[i,j]
                    if H-L < 1e-12 or eta <= 1e-12:
                        continue
                    newj = np.clip(aj + y[j]*(E[i]-E[j])/eta, L, H)
                    if abs(newj-aj) < 1e-10:
                        continue
                    newi = ai + y[i]*y[j]*(aj-newj)
                    b1 = b-E[i]-y[i]*(newi-ai)*K[i,i]-y[j]*(newj-aj)*K[i,j]
                    b2 = b-E[j]-y[i]*(newi-ai)*K[i,j]-y[j]*(newj-aj)*K[j,j]
                    b = b1 if 1e-9 < newi < self.C-1e-9 else b2 if 1e-9 < newj < self.C-1e-9 else (b1+b2)/2
                    a[i], a[j] = newi, newj
                    snapshot([int(i),int(j)],{'L':float(L),'H':float(H),'eta':float(eta)})
                    changed += 1
                    break
            if changed == 0:
                break
        self.alpha_, self.coef_, self.intercept_ = a, (a*y) @ X, b
        self.n_iter_ = iteration+1
        margins = y*self.decision_function(X)
        residuals = np.where(a < 1e-8, np.maximum(0,1-margins),
                    np.where(a > self.C-1e-8,np.maximum(0,margins-1),abs(margins-1)))
        self.kkt_residual_ = float(residuals.max())
        self.converged_ = self.kkt_residual_ <= max(10*self.tol,1e-3)
        self.support_ = np.flatnonzero(a>1e-8)
        return self

    def decision_function(self, X):
        return np.asarray(X) @ self.coef_ + self.intercept_

    def predict(self, X):
        return np.where(self.decision_function(X)>=0,1,-1)
X = np.array([[-2,-1],[-2,1],[-1,0],[1,0],[2,-1],[2,1]], float)

11.8 练习与解答

  1. 找到代码中“只从当前训练折学习标准化”的具体位置。
  2. 若把 fold 加入特征，模型在学什么？
  3. 重新设计网格前，应记录什么，怎样保持评估可信？
提示参考解答
  1. Python在Pipeline的fit内；R在每折的 learn_scale(X_train[a,])。验证数据只经过apply/transform。
  2. 学到人为分配的实验编号，输入含义不再是花的测量，部署时也没有相同编号机制。
  3. 预先记录候选、指标、划分和变更理由；在训练验证内比较。如果不断依据测试结果改网格，这份测试集已参与选择，需要另设最终评估。
