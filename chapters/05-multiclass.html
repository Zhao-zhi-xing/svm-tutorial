7  多分类：分数、投票与联合学习

本章目标：区分二分类归约、预测规则和联合目标。原笔记介绍过 OvR、OvO、DAGSVM，但没有充分解释模糊区域和软件实现。本章以《神经网络与深度学习》第 3.1.2 节、图 3.3 为起点，重新绘制可交互的示意 (邱锡鹏 2020年)。

7.1 三种图，不只是三种算法名称

7.2 一对其余：训练 \(K\) 个二分类器

第 \(k\) 个模型把类别 \(k\) 标为正类，其余全部标为负类，得到 \(f_k(x)\)。如果只采用“唯一一个正分数”的符号规则，会出现全负或多个为正的区域；这正是图 3.3 展示的歧义。

实际常用预测为

\[\hat y(x)=\operatorname*{argmax}_{k=1,\ldots,K} f_k(x). \tag{7.1}\]

它使用同一组 OvR 模型的分数，给出了明确选择规则。最高分完全相同仍需要平票约定；不同二分类器的分数尺度也可能不一致，所以 argmax 不等于“概率最大”。类别多时，一对其余会产生严重的正负样本不平衡，需要考虑类别权重、评价指标和校准。

注记argmax 是预测操作，不指定训练方式

独立训练的 OvR SVM、联合训练的多分类 SVM、多项逻辑回归和神经网络都可以使用 argmax。仅从这条预测公式无法判断模型优化的是哪个目标。教材把它作为多分类决策方式讨论，本教程进一步区分其训练来源。

7.3 一对一：训练 \(K(K-1)/2\) 个分类器

每个模型只看到两个类别的数据，预测时投给其中一个类别，再选择票数最高者。类别对本身也可能不平衡，所以“一对一不会出现不平衡”是错误结论。

分类器更多不必然意味着训练更慢：每个分类器使用的数据更少，速度和内存取决于规模、求解器、特征与缓存。预测需要组合许多成对结果，类别很多时成本才更明显。

三类时可能出现循环：\(0\) 胜 \(1\)，\(1\) 胜 \(2\)，\(2\) 胜 \(0\)，票数各为 1。图中的灰色区域直接显示原始投票的歧义；实际软件通常有确定的平票处理。

7.4 scikit-learn 最容易误读的参数

SVC 的多分类训练采用 LIBSVM 的 OvO。decision_function_shape='ovr' 只是把成对结果转换成每类一个分数的输出形状，不会把训练改成 OvR。想显式采用 OvR，应使用 OneVsRestClassifier。

from sklearn.svm import SVC, LinearSVC
from sklearn.multiclass import OneVsRestClassifier
df = lab.load_data('iris')
features = [c for c in df if c not in ['id','split','fold','target']]
tr = df[df.split == 'train']; te = df[df.split == 'test']
X, y = tr[features], tr.target
# 标准化置于归约分类器外部，同一变换作用于所有类别。
ovo = lab.Pipeline([('scale',lab.StandardScaler()),
    ('svm',SVC(kernel='linear',decision_function_shape='ovo'))]).fit(X,y)
ovr = lab.Pipeline([('scale',lab.StandardScaler()),
    ('svm',OneVsRestClassifier(SVC(kernel='linear')))]).fit(X,y)
print('OvO 成对输出形状:', ovo.decision_function(te[features]).shape)
OvO 成对输出形状: (45, 3)
print('OvR 类别输出形状:', ovr.decision_function(te[features]).shape)
OvR 类别输出形状: (45, 3)

对三类，两种形状都恰好是三列，不能靠列数区分语义；对四类才分别是 6 列和 4 列。SVC(break_ties=True) 在 decision_function_shape='ovr' 的条件下利用转换分数处理投票平票；本教程示意图直接显示平票，不冒充该实现。

LinearSVC 默认是 OvR；设置 multi_class='crammer_singer' 才采用联合多分类目标。SVC(kernel='linear') 和 LinearSVC 也不完全相同：求解器、损失和截距处理等默认设置不同。

7.5 联合多分类 SVM

Crammer–Singer 形式对每个类别学习 \(w_k\)（这里省略截距写法）：

\[\min_{W,\xi}\frac12\sum_k\|w_k\|^2+C\sum_i\xi_i,\]

\[w_{y_i}^Tx_i-w_k^Tx_i\ge1-\xi_i\quad(k\ne y_i),\qquad \xi_i\ge0.\]

对应损失是 \(\max(0,\max_{k\ne y_i}[1+f_k(x_i)-f_{y_i}(x_i)])\)。它要求真类分数比所有错误类高出间隔，类别参数在一个目标中耦合。这与独立 OvR 的 \(K\) 个二分类目标不同 (Crammer 和 Singer 2001年)。

预测边界由 \(f_i(x)=f_j(x)\) 给出，即 \((w_i-w_j)^Tx+(b_i-b_j)=0\)。但该直线的某部分若被第三类更高分“覆盖”，就不会成为最终边界。图中虚线全部显示分数相等线，彩色区域才是最终预测。

7.5.1 从联合约束推导多分类 hinge

固定所有类别分数，Crammer–Singer约束要求 \(\xi_i\ge1+f_k(x_i)-f_{y_i}(x_i)\)（所有 \(k\ne y_i\)），同时 \(\xi_i\ge0\)。因为 \(C>0\)，

\[\xi_i^*=\max\{0,\max_{k\ne y_i}[1+f_k(x_i)-f_{y_i}(x_i)]\}.\]

所以最严重的竞争类别决定本样本损失；它不是把 \(K-1\) 个竞争损失简单求和，也不是分别训练 \(K\) 个OvR二分类器。若唯一最大竞争者为 \(k^*\) 且损失为正，该项对 \(w_{k^*}\) 的梯度是 \(x_i\)，对 \(w_{y_i}\) 是 \(-x_i\)；其余类别为0。并列或恰好达到0时使用这些梯度的凸组合，说明为何称为次梯度。

argmax的两类分数相等条件为 \(f_i=f_j\)；成为实际决策边界还需 \(f_i=f_j\ge f_k\) 对所有其余类别成立。这个额外条件解释了图中部分虚线为何不是最终边界。

OvO取所有无序类别对，共 \(\binom K2=K(K-1)/2\) 个模型。若本图的 \(h_{ij}\ge0\) 投给较大编号 \(j\)，否则投给 \(i\)，票数为

\[v_k(x)=\sum_{i<j}\big[\mathbf1\{h_{ij}(x)\ge0\}\mathbf1\{k=j\}+\mathbf1\{h_{ij}(x)<0\}\mathbf1\{k=i\}\big].\]

之后再对 \(v_k\) 取argmax；票数并列仍要单独规定处理。二分类分数先组合成票数、再作类别选择，与直接对独立OvR分数取argmax是两条不同的预测流程。

7.6 DAGSVM 与 ECOC

DAGSVM 复用 OvO 训练模型，预测沿淘汰路径进行，通常每个样本只需要 \(K-1\) 次成对判断。它改变推理流程，淘汰顺序可能影响错误传播，不是对投票的普遍改进保证 (Platt 等 1999年)。

ECOC 给每个类别分配码字，把若干类别分组形成二分类问题，再用预测码与类别码的距离解码。它可以引入冗余以提高容错，但效果取决于编码设计、二分类器错误相关性和解码规则；更长码不保证更准确。

7.8 练习与解答

  1. 四类问题，OvR 和 OvO 分别需要多少个分类器？
  2. 一个点的 OvR 分数为 \((-0.2,-0.1,-0.5)\)。符号规则与 argmax 分别怎样判断？
  3. 如果两个类别票数相同，怎样设计透明的平票规则？
提示参考解答
  1. 分别为 4 和 6。
  2. 符号规则全负，无法唯一分类；argmax 选第二类（若用从 0 开始的编号，为类别 1）。
  3. 可规定使用汇总分数，再以固定类别顺序处理完全同分。必须在评估前固定规则，不能看测试标签选择规则。
