10  可靠评估与模型选择

本章要回答：怎样区分“训练模型成功”与“有证据相信它能预测新样本”？

前置知识：预测标签、分类分数、多分类规则。先手算指标，再组织模型选择流程。

10.1 从十个预测结果计算混淆矩阵

假设测试集10个样本，真实正类4个，模型找到其中3个、漏掉1个；真实负类6个，误报其中2个、正确排除4个。

真实类别 负类 正类
负类 \(TN=4\) \(FP=2\)
正类 \(FN=1\) \(TP=3\)

行表示真实、列表示预测。\(TP\) 为找到的正类，\(FN\) 为漏掉的正类，\(FP\) 为误报，\(TN\) 为正确识别的负类。

\[\mathrm{Accuracy}=\frac{TP+TN}{n}=\frac7{10}=0.7,\]

\[\mathrm{Precision}=\frac{TP}{TP+FP}=\frac35=0.6, \qquad\mathrm{Recall}=\frac{TP}{TP+FN}=\frac34=0.75.\]

precision 问“预测为正中有多少是真的”，recall 问“真实正类有多少被找到”。分母代表不同人群，不能互换。

10.2 F1：为什么不能只看 precision 或 recall

先把符号说清楚：\(P\) 表示 precision（查准率），\(R\) 表示 recall（查全率），二者都不是 F1。上例中 \(P=0.6\)，\(R=0.75\)。查准率问“我报出的正类有多可靠”，查全率问“我找全了多少真实正类”。

只看查全率，可以把所有10个样本都报为正：4个正类全被找到，\(R=1\)，但 \(P=4/10=0.4\)。只追求查准率，也可能只报出一个很有把握的正类，漏掉大量正类。我们需要同时检查这两个方向。

10.2.1 从调和平均一步步得到 F1

算术平均 \((P+R)/2\) 比较宽容。例如 \(P=0.1,R=0.9\) 时平均数为0.5，但很低的查准率仍然是严重问题。F1 使用调和平均：先平均倒数，再取倒数。

\[ F_1=\frac{1}{\frac12\left(\frac1P+\frac1R\right)} =\frac{2}{\frac1P+\frac1R} =\frac{2PR}{P+R}. \tag{10.1}\]

最后一步只是在分子分母同乘 \(PR\)。\(P,R\) 越不均衡，调和平均越受较小的一项限制：\(0.1\) 与 \(0.9\) 的 F1 为 \(2\times0.1\times0.9/(0.1+0.9)=0.18\)，明显低于算术平均0.5；若 \(P=R=q\)，则 \(F_1=q\)。

回到十样本例，逐项代入，不必死记字母：

\[F_1=\frac{2\times0.6\times0.75}{0.6+0.75} =\frac{0.9}{1.35}=\frac23\approx0.667.\]

也可以直接从混淆矩阵得到同一结果。把 \(P=TP/(TP+FP)\)、\(R=TP/(TP+FN)\) 代入：

\[ \begin{aligned} F_1 &=\frac{2\frac{TP}{TP+FP}\frac{TP}{TP+FN}} {\frac{TP}{TP+FP}+\frac{TP}{TP+FN}}\\ &=\frac{2TP^2}{TP(TP+FN)+TP(TP+FP)}\\ &=\frac{2TP}{2TP+FP+FN} =\frac{2\times3}{2\times3+2+1}=\frac69. \end{aligned} \tag{10.2}\]

这个化简假设 \(TP>0\)。实际计算中，若 \(TP=0\) 而存在漏报或误报，则 F1 为0；若 \(TP=FP=FN=0\)，该类在真实和预测中都不存在，分式是 \(0/0\)，必须声明处理约定。本教程实践采用 zero_division=0，并同时列出每类真实样本数，避免用一个0掩盖“根本没有这一类”的情况。

F1 在0与1之间，越高表示这两个方向的综合表现越好，但它没有使用 \(TN\)。模型全预测负类时，本例仍有60%准确率，却得到正类 F1 为0。F1 不能替代整个混淆矩阵，也不是所有任务都应默认最大化的指标。

10.2.2 Fβ：需要更重视漏报时怎么办

F1 对查准率与查全率对称。若更重视找全正类，可以用 \(F_\beta\)，其中 \(\beta>0\)：

\[ F_\beta=\frac{(1+\beta^2)PR}{\beta^2P+R} =\frac{1+\beta^2}{\frac1P+\frac{\beta^2}{R}}. \tag{10.3}\]

第二种写法显示：这仍是加权调和平均；recall 的倒数项权重是 \(\beta^2\)。因此 \(\beta>1\) 更重视 recall，\(0<\beta<1\) 更重视 precision，\(\beta=1\) 回到 F1。注意，\(\beta=2\) 对应的是平方权重4，不是把 recall 简单乘2。

代入混淆矩阵可以看出错在哪里会被更多惩罚：

\[F_\beta=\frac{(1+\beta^2)TP}{(1+\beta^2)TP+\beta^2FN+FP}.\]

当 \(\beta=2\) 时，分母的漏报项是 \(4FN\)，误报项仍为 \(FP\)。当 \(\beta=0.5\) 时，漏报项只有 \(0.25FN\)。这帮助你理解指标的侧重，但它不是实际业务收益或成本的完整模型。

指标 逐项代入本例 \(TP=3,FP=2,FN=1\) 结果 侧重
\(F_{0.5}\) \(\frac{1.25\times3}{1.25\times3+0.25\times1+2}\) 0.625 更重视查准率
\(F_1\) \(\frac{2\times3}{2\times3+1+2}\) 约0.667 对称兼顾两者
\(F_2\) \(\frac{5\times3}{5\times3+4\times1+2}\) 约0.714 更重视查全率

本例 recall 高于 precision，因此侧重 recall 的 \(F_2\) 较高；这不表示把指标从 F1 换成 F2 就使模型变好了。比较模型时必须事先固定指标和 \(\beta\)，不能看完测试结果再挑一个更好看的指标。定义和软件约定可查 scikit-learn 的 Fβ 文档。

10.3 多分类 F1：macro、micro、weighted 分别在平均什么

多分类没有唯一的一对 \(TP,FP,FN\)。先对每一类做“该类是正类、其余都是负类”的计数，再决定如何汇总。这是计算评估指标的方式，与前面训练模型使用 OvR 还是 OvO 无关。

用同一个三分类混淆矩阵完成三种平均方式的手算，行是真实类别，列是预测类别：

真实类别 A B C 真实样本数（support）
A 8 1 1 10
B 2 3 0 5
C 1 0 1 2

共有17个样本，正确分类 \(8+3+1=12\) 个。以 A 为例：\(TP_A=8\)；预测成 A 却不是真实 A 的有 \(2+1=3\) 个，所以 \(FP_A=3\)；真实 A 却预测成 B/C 的有 \(1+1=2\) 个，所以 \(FN_A=2\)。对 B、C 同理：

类别 \(TP_k\) \(FP_k\) \(FN_k\) \(P_k\) \(R_k\) \(F_{1,k}\)
A 8 3 2 \(8/11\) \(8/10\) \(16/21\approx0.762\)
B 3 1 2 \(3/4\) \(3/5\) \(6/9\approx0.667\)
C 1 1 1 \(1/2\) \(1/2\) \(2/4=0.500\)

10.3.1 macro：每个类别一票

先分别算出每一类的 F1，再不加权平均：

\[F_1^{\mathrm{macro}}=\frac1K\sum_{k=1}^K F_{1,k} =\frac{16/21+2/3+1/2}{3}\approx0.643.\]

A 有10个样本，C 只有2个样本，但二者对 macro-F1 的权重均为 \(1/3\)。因此小类别表现差也能明显拉低指标。教程案例用它选参，是为了不让较多样本的类别完全主导评价。

不要交换运算顺序：平均各类 F1，一般不等于先平均各类 precision 和 recall，再套一次二分类 F1 公式。非线性运算的次序会改变结果。

10.3.2 weighted：按真实类别人数加权

记 \(n_k\) 为真实类别 \(k\) 的样本数，\(N=\sum_k n_k\)：

\[F_1^{\mathrm{weighted}}=\sum_{k=1}^K\frac{n_k}{N}F_{1,k} =\frac{10(16/21)+5(2/3)+2(1/2)}{17}\approx0.703.\]

A 的权重为 \(10/17\)，C 为 \(2/17\)，因此本例 weighted 更靠近表现较好的 A。它能反映样本构成，但大量多数类可能掩盖少数类的低分。这里的 weighted 是评估的加权平均，不等于训练 SVM 时设置 class_weight；训练和评价是两件不同的事。

10.3.3 micro：先汇总计数，再计算一个 F1

\[TP_{\mathrm{all}}=\sum_kTP_k=12,\quad FP_{\mathrm{all}}=\sum_kFP_k=5,\quad FN_{\mathrm{all}}=\sum_kFN_k=5.\]

先使用这些总数计算 precision、recall，再得到 F1：

\[P_{\mathrm{micro}}=\frac{12}{12+5},\quad R_{\mathrm{micro}}=\frac{12}{12+5},\]

\[F_1^{\mathrm{micro}}=\frac{2\times12}{2\times12+5+5}=\frac{12}{17}\approx0.706.\]

为什么与 accuracy 相同？在单标签多分类、纳入全部类别时，每个正确样本贡献一个 \(TP\)；每个错误样本同时给“被误报的类别”贡献一个 \(FP\)、给“被漏掉的真实类别”贡献一个 \(FN\)。所以总 \(FP\) 和总 \(FN\) 都等于错误样本数，micro precision、recall、F1 就都等于正确样本比例。

若一个样本可有多个标签，或只评价某些类别，这个等式一般不成立。不能把它当作所有分类任务的通用公式。三种平均方式和零分母约定可查 scikit-learn 的指标说明。

平均方式 运算顺序 谁有更大影响 本例
macro 每类 F1 → 等权平均 各类相同 约0.643
weighted 每类 F1 → 按真实人数加权 人数多的类 约0.703
micro 先合计 TP/FP/FN → 算 F1 每个样本；错误被统一累计 约0.706

若99%的样本为负，全预测负类也有99%accuracy，但正类 recall 和 F1 为0。确定主指标时，先明确最需要识别哪类、漏报与误报的影响，再同时报告每类分数和 support。

检验理解：本例中 C 类只有两个真实样本，如果全被漏掉，哪一种平均更容易明确暴露这个类别的问题？macro 对 C 仍给 \(1/3\) 权重，而 weighted 只给 \(2/17\)；不过最直接的证据仍是 C 类 recall、F1 和混淆矩阵。宏平均也不能代替逐类检查。

10.4 从一个阈值到一条排序曲线

SVM 产生分数，按 \(f(x)\ge t\) 判正类。降低 \(t\) 会纳入更多样本，可能同时增加 \(TP\) 与 \(FP\)。

  • ROC：横轴 \(FPR=FP/(FP+TN)\)，纵轴 \(TPR=Recall\)。
  • PR：横轴 Recall，纵轴 Precision。

排序曲线需要分数相对大小，不要求分数为概率。以降序分数 \(3,2,1,0\)、标签“正、负、正、负”为例：

纳入的前几个样本 TP FP Recall Precision FPR
1 1 0 0.5 1 0
2 1 1 0.5 0.5 0.5
3 2 1 1 2/3 0.5
4 2 2 1 0.5 1

ROC-AUC 是随机正样本分数超过随机负样本的概率，平分计半。本例四对正负比较中有三对排序正确，AUC为0.75。

\[\mathrm{AUC}=\frac1{n_+n_-}\sum_{i:y_i=1}\sum_{j:y_j=-1} \left[\mathbf1\{f_i>f_j\}+\tfrac12\mathbf1\{f_i=f_j\}\right].\]

AP 按 recall 的增加加权对应 precision：\(\mathrm{AP}=\sum_l(R_l-R_{l-1})P_l\)。本例为 \(0.5\cdot1+0.5\cdot2/3=5/6\)。它不同于随意连直线得到的 PR 梯形面积。

类别比例影响 PR 的解释；严重不平衡时同时看少数类指标与 PR。选择部署阈值仍应在训练/验证数据中完成。

10.5 为什么必须留出测试集

若试10组 \(C,\gamma\)，然后选测试分数最高的那组，这个测试集已参与模型选择。最终报告的分数会受到选择偏差影响。

正确流程是：预先规定指标与候选 → 留出测试集 → 在训练集内选择参数 → 用全部训练集重拟合 → 最后评估一次测试集。测试集回答的是整个已选流程的未知样本表现，而不只某个已知参数的表现。

样本少时可用外层交叉验证评估、内层交叉验证选参，即嵌套验证；每个外层测试折都不能参与那轮选择。

10.6 五折验证怎样运转

将训练集分成五份。固定一组候选参数，每次用四份训练、一份验证，得到五个分数并取平均。对所有候选重复，选均分最高的参数。

最后用整个训练集重拟合。五折均分是选参过程中使用的分数，选择过后的最佳均分不能当作独立、无偏的泛化评估。

候选模型怎样被比较

悬停读取每组 C、γ 的训练集五折 macro-F1；最优组合由验证分数决定。

自测：这个热图能否证明最佳格子在所有未来数据上最好？不能；它是在有限训练数据上选择参数的依据。独立测试用于检查选出的流程。

10.7 所有会学习参数的预处理都在折内

标准化学习均值和标准差，填补学习中位数或众数，类别编码学习类别字典，特征筛选可能学习标签关系。每个验证折都必须用其余四折拟合这些操作。

先在全数据上标准化再分折，会让验证数据影响训练变换；先用全部标签选特征更直接泄漏。Python Pipeline 和 R 的显式折循环将在实践篇落实这条原则。

独立样本演示可分层随机划分；同一受试者多行记录应按组划分；预测未来应按时间划分。划分方式来自任务，而非一律打乱。

10.7.1 标准化改变了哪一个几何空间

设 \(z=A(x-\mu)\)，\(A=\operatorname{diag}(1/s_r)\)。若标准化空间模型为 \(v^Tz+c\)，原始坐标中

\[w_{\rm raw}=A^Tv,\qquad b_{\rm raw}=c-w_{\rm raw}^T\mu.\]

原坐标参考带宽为 \(2/\|w_{\rm raw}\|\)，标准化空间为 \(2/\|v\|\)；优化正则项使用后者的权重范数。不能把两种坐标的长度混为一个量。

一个特征放大1000倍之后

先预测边界是否改变，再比较处理方式；图始终保留原始坐标。

两种固定配置均使用 \(C=1,\gamma=\text{scale}\)；scale 是按输入方差求参数的规则，实际数值不同，卡片列出实际值。标准化只拟合训练集。这是机制对照，不证明每个任务标准化都会提高精度。

10.8 类别加权、阈值与重采样

类别加权将损失写成 \(\sum_i C_i\ell(m_i)\)，提高某类的违例价格。阈值改变最终判定规则，重采样改变训练样本的构成；三种操作需分别评估。

提高少数类代价，会改变哪些指标？

比较普通与加权模型；先解释少数类 recall，再检查 precision 的代价。

balanced 权重从训练标签计算。加权不保证所有指标同时改善；阈值或权重若需要选择，仍放在训练验证中。重采样也必须在训练折内，否则复制样本可能跨到验证折。

10.9 好的排序不等于可信概率

将分数直接取 sigmoid 并不自动获得概率。校准通过训练集内的留出或交叉验证，学习分数与正类频率之间的关系。sigmoid 拟合参数较少；isotonic 更灵活，但数据少时可能过拟合。

Brier 分数 \(\frac1n\sum_i(p_i-\mathbf1\{y_i=+1\})^2\) 越低越好；log loss 对自信但错误的预测惩罚更重。可靠性图按预测概率分箱，比较平均预测概率与实际频率。

预测0.8的样本，是否约有80%为正类？

切换方法，查看分箱样本数、Brier和log loss；不要只看曲线是否贴近对角线。

对照的未校准基线只对分数直接取sigmoid；另两种方法在训练集内校准完整Pipeline，并使用交叉验证集成。有限分箱有采样波动，方法优劣不能据一次图确定。

10.10 练习与解答

  1. 首个十样本例中，若把漏报的一个正类改为正确预测，其他不变，新的 recall 和 precision 是多少？
  2. 每个候选都在测试集上评估，再取最高者，为什么不能把最高值叫独立测试结果？
  3. 哪些任务不适合普通随机行划分？
提示参考解答
  1. \(TP=4,FN=0,FP=2\)，recall为1，precision为 \(4/6=2/3\)。先改计数再算分母。
  2. 测试标签影响了选参，最高值反映真实能力与选择噪声。需新的未见评估，或从开始采用外层评估。
  3. 同一人的重复记录、时间序列、同一地点或设备的聚类采样等。划分应隔离预期部署中的未知单位或未来时间。
