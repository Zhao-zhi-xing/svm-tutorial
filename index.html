开始学习：分类问题与超平面

赵知行 · 更新于2026年10月3日

你会学到什么

分类正确的直线往往不止一条，SVM 如何作出选择？数据重叠后为什么仍能训练？一条输入空间中的曲线为什么能对应另一个空间的超平面？求解器如何得到模型，预测与评估又怎样衔接？

学完后，你应能够解释这些问题，独立推导线性 SVM 的原始问题与对偶问题，检查 KKT 条件，完成一次 SMO 更新，并使用 Python 或 R 建立可复现的实验。

先备知识

默认你理解向量内积、范数、矩阵运算、偏导数与基本概率。涉及 SVM 的优化条件、核函数和评价指标时，会从例子开始解释。推导中的每个新符号都在出现处定义。

教程结构

  • 从问题到模型：分类问题与超平面 → 间隔与硬间隔 → 软间隔与正则化。
  • 理解模型如何求解：约束优化与 KKT → SVM 对偶与参数恢复 → 特征映射与核 → 核的函数空间 → SMO。
  • 建立完整分类任务：多分类 → 可靠评估与模型选择。
  • 动手与继续研究：Python/R 完整实验 → Iris、Heart、Khan 案例 → 现代研究导读。

首次学习建议顺序阅读。先在图上预测结果，再操作控件，最后对照推导；练习的参考答案可以展开查看。编程实践安排在理论之后，你也可以完成一个理论主题后，回到实践篇检查相应代码。

如何阅读图与公式

二维二分类图使用蓝色表示负类、橙色表示正类；深色实线表示决策边界，虚线表示规范化后的参考间隔线。手动调整的直线与训练得到的最优模型会分别注明。需要训练的交互使用预先计算的模型，切换选项即可比较结果。

主要参考 ISL、CS229、Support Vector Machines Succinctly，以及《神经网络与深度学习》的多分类讲解。正文提供引用，完整条目见参考文献。
